# 消息防抖动

本插件用于将同一聊天来源在短时间内连续发送的多条消息合并为一条，再交给 NekroAgent 处理，减少“我想说的是……”这类碎片消息造成的过早回复和上下文割裂。

## 功能

- 私聊防抖默认开启，群聊默认关闭。
- 群聊开启后按“聊天频道 + 发送者”隔离，不会把不同用户的消息合并到一起。
- 支持固定防抖和自适应防抖：会根据文本长度、结尾标点、连续短消息数量调整等待时间。
- 设置最大总等待时间，连续发送不会无限期等待。
- 合并文本消息，并保留图片、文件、语音、视频、引用、转发等非文本消息段。
- 以命令前缀开头的消息不参与合并，并放行给命令系统；已有缓冲会先结算。
- 可配置用户白名单/黑名单。黑名单用户直接使用系统原有流程，不参与防抖。
- 识别可用的输入状态通知，在输入期间延长等待，并带有超时保护。
- 频道重置或插件卸载时自动取消计时器、清理会话。
- 合并消息会写入一条历史记录，原始碎片不会重复写入，避免上下文膨胀。

## 配置建议

| 配置 | 默认值 | 说明 |
| --- | ---: | --- |
| `ENABLE` | `true` | 总开关 |
| `ENABLE_PRIVATE` | `true` | 私聊防抖 |
| `ENABLE_GROUP` | `false` | 群聊防抖；开启后按发送者隔离 |
| `DEBOUNCE_TIME` | `2` | 固定模式等待秒数 |
| `MERGE_SEPARATOR` | 换行 | 合并消息分隔符 |
| `ENABLE_ADAPTIVE` | `true` | 自适应等待 |
| `ADAPTIVE_MIN_WAIT` | `1` | 单轮最短等待秒数 |
| `ADAPTIVE_MAX_WAIT` | `6` | 单轮最长等待秒数 |
| `ADAPTIVE_MAX_TOTAL_WAIT` | `12` | 一次连续消息的最大总等待秒数 |
| `ENABLE_TYPING_DETECTION` | `true` | 输入状态感知 |
| `MAX_TYPING_WAIT` | `60` | 输入状态超时保护 |
| `ENABLE_RECALL_FILTER` | `true` | 过滤防抖窗口内被标记撤回的消息 |
| `ID_ACCESS_MODE` | `全部用户` | 下拉选择 `全部用户`、`白名单` 或 `黑名单`；兼容旧配置值 `all`、`whitelist`、`blacklist` |
| `ID_LIST` | `[]` | 用户平台 ID 列表 |
